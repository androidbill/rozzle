    How To Play Rozzle

    Rozzle is a 2-4 player push-your-luck dice game where players aim to be the first to reach 10,000 points. Players roll six dice, set aside scoring combinations, and either bank points or risk them by re-rolling remaining dice.

    Basic Scoring

      Key Terms

      • Rozzle: If no scoring dice appear in a roll, you lose all points accumulated in that turn.
      • Hot Dice: If all six dice score, pick up all six and roll again.
      • Opening Score: Some tables require 500 or 1000 to begin banking.
      • Winning: First to 10,000+ wins, though some tables allow one final round.
